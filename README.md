# 首都圏 駅別ラーメンDB（東京・神奈川・埼玉・千葉）🍜

首都圏の各駅ごとに、徒歩圏の **おすすめラーメン店** を数店ずつ集めたデータベースです。「降りた駅から、すぐに旨い一杯にたどり着く」ことを目的にしています。

- **最終更新:** 2026-05-29
- **収録:** **全1,161店**（東京23区704・東京多摩96・神奈川158・埼玉122・千葉81）
- **対象範囲:**
  - **東京都(23区)**: 全鉄道（JR・東京メトロ・都営地下鉄＋東急・京王・小田急・京急・西武・東武・京成・都電・ゆりかもめ 等）
  - **東京都(多摩)**: 立川・八王子・吉祥寺/三鷹・調布/府中・町田・西東京/小平ほか多摩地区の主要駅
  - **神奈川県**: 横浜市18区・川崎市7区を区単位、加えて湘南（藤沢・鎌倉・茅ヶ崎・平塚・小田原）・県央（相模原・厚木・海老名・大和・座間）の主要駅
  - **埼玉県**: さいたま市全区を中心に、川口・蕨・戸田・所沢・川越・越谷・草加・春日部・熊谷ほか県南〜県北の主要駅
  - **千葉県**: 船橋・松戸・柏・市川/浦安・千葉市・流山/我孫子・成田/八千代ほか県北西〜郊外の主要駅
- **作り方:** 検証優先・段階的(phased)。Webで実在・営業中を確認できた店のみを掲載します。

## 🧭 データ構造・凡例

各駅セクションは次のテーブル形式です。

| 列 | 内容 |
|---|---|
| **店名** | 店舗の正式表記 |
| **ジャンル** | 醤油 / 塩 / 味噌 / とんこつ / 家系 / 二郎・二郎系 / 煮干し / つけ麺 / 担々麺 / 鶏白湯 / 油そば・まぜそば / 中華そば / その他 |
| **看板・特徴** | 看板メニューや一言の特徴 |
| **評価の目安** | 食べログ点数、ラーメン百名店選出、ミシュラン(星/ビブグルマン)など(取得できた範囲) |
| **出典** | 食べログを基本に、公式/ブログ/ラーメンDBの店舗ページなど |

### 評価の目安について
- **食べログ点数**は調査時点(2026年5月)の値で、変動します。目安として **3.5 以上**は高評価、**3.6 以上**は屈指の人気店、**3.8 以上**はエリア最高峰クラスです。
- **ラーメン百名店**は食べログによる年間TOP100選出店、**ビブグルマン/星**はミシュランガイド(掲載時点で判明したもの)。
- **ラーメンDB(ramendb.supleks.jp)** は自動アクセスが現在 **403でブロック**されており、点数の自動取得ができません。そのため定量指標は食べログを代理指標とし、点数を確認したい場合はブラウザで各ページを開いてください。

ブラウザで **都県・区市・ジャンル・認定・点数・キーワード**で絞り込めるビューアを `docs/` に用意しています(依存ライブラリなしの単一HTML + `docs/data/ramen.json`、全1,161店)。

- 公開URL（Pages有効化後）: **https://off53jub.github.io/RamenResearch/**
- ソース: [`docs/index.html`](docs/index.html)

**有効化手順**（リポジトリ設定が必要。1回だけ）:
1. GitHub の **Settings → Pages** を開く
2. **Source** = "Deploy from a branch"
3. **Branch** = `main`（PRマージ後）または `claude/sharp-tesla-Nhqmg`、**Folder** = `/docs` を選んで Save
4. 数分後に上記URLで公開されます

> ローカル確認: `python3 -m http.server -d docs 8000` → http://localhost:8000/ （`file://` 直開きは fetch がCORSで失敗します）

## ⚠️ 注意事項・免責

- 掲載は **実在・営業中を確認できた店のみ**です。架空の店は載せていません。確認できなかった駅は無理に埋めず該当区ファイル内に「**要調査(phase2)**」として残しています。
- 飲食店は **閉店・移転・休業・営業時間変更** が起こり得ます。訪問前に各店の最新情報(食べログ/公式SNS等)をご確認ください。
- 点数・百名店などの評価は **掲載時点のスナップショット** です。
- 「最寄り駅」は徒歩圏(目安10分以内)で割り当てています。複数駅が近い店は、最も近い駅に寄せています。
