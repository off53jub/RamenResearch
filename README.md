# 東京23区 駅別ラーメンDB 🍜

東京23区の各駅ごとに、徒歩圏の **おすすめラーメン店** を数店ずつ集めたデータベースです。「降りた駅から、すぐに旨い一杯にたどり着く」ことを目的にしています。

- **最終更新:** 2026-05-29
- **対象範囲:** 東京23区内の鉄道全駅。**第1段階は JR・東京メトロ・都営地下鉄**を全区で収録し、私鉄が中心の **目黒区・大田区・世田谷区は全鉄道(東急・京王・小田急・京急 等)** を収録済み。その他の区の **私鉄駅(西武・東武・京成・京急・東急・京王井の頭 等)は次ラウンドで追記**します(各区ファイル末尾に対象を明記)。
- **作り方:** 検証優先・段階的(phased)。Webで実在・営業中を確認できた店のみを掲載します。

## 🧭 データ構造・凡例

各駅セクションは次のテーブル形式です。

| 列 | 内容 |
|---|---|
| **店名** | 店舗の正式表記 |
| **ジャンル** | 醤油 / 塩 / 味噌 / とんこつ / 家系 / 二郎・二郎系 / 煮干し / つけ麺 / 担々麺 / 鶏白湯 / 油そば・まぜそば / 中華そば / その他 |
| **看板・特徴** | 看板メニューや一言の特徴 |
| **評価の目安** | 食べログ点数、ラーメン百名店選出、ミシュラン(星/ビブグルマン)など(取得できた範囲) |
| **出典** | 食べログを基本に、公式/ブログ/ラーメンDBの店舗ページなど |

### 評価の目安について
- **食べログ点数**は調査時点(2026年5月)の値で、変動します。目安として **3.5 以上**は高評価、**3.6 以上**は屈指の人気店、**3.8 以上**はエリア最高峰クラスです。
- **ラーメン百名店**は食べログによる年間TOP100選出店、**ビブグルマン/星**はミシュランガイド(掲載時点で判明したもの)。
- **ラーメンDB(ramendb.supleks.jp)** は自動アクセスが現在 **403でブロック**されており、点数の自動取得ができません。そのため定量指標は食べログを代理指標とし、点数を確認したい場合はブラウザで各ページを開いてください。

## ⚠️ 注意事項・免責

- 掲載は **実在・営業中を確認できた店のみ**です。架空の店は載せていません。確認できなかった駅は無理に埋めず該当区ファイル内に「**要調査(phase2)**」として残しています。
- 飲食店は **閉店・移転・休業・営業時間変更** が起こり得ます。訪問前に各店の最新情報(食べログ/公式SNS等)をご確認ください。
- 点数・百名店などの評価は **掲載時点のスナップショット** です。
- 「最寄り駅」は徒歩圏(目安10分以内)で割り当てています。複数駅が近い店は、最も近い駅に寄せています。
